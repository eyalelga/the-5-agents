# SKILL — obsidian-bases

## Overview

Skill ליצירת קבצי Obsidian Bases (`.base`) — תצוגות דינמיות של notes בסגנון database. תומך ב-table, cards, ו-list views עם filters, formulas, ו-summaries.

## תפקיד

מאפשר יצירת "database views" מעל קבצי vault. מסנן notes לפי tags, properties, או תיקיות, ומציג אותם בטבלאות או כרטיסיות.

## שימושים אפשריים בפרויקט

- תצוגת כל ה-agents עם הסטטוס שלהם
- dashboard של כל המשימות הפתוחות
- סקירת session logs לפי תאריך
