# PRD — Babysitting Tracker — Mobile HTML App

## מטרת המוצר
אפליקציית HTML עצמאית (קובץ אחד, ללא שרת) למעקב שעות בייביסיטינג עבור 2 ילדים משתי משפחות. פועלת בסמארטפון — צפייה ועריכה מלאה.

---

## משתמש יעד
הורה / מטפלת שמנהלת בייביסיטינג עבור שני ילדים.

---

| אריאל | בן | כחול (#5BA4CF) | שם חבן |

## מסכים (4 tabs בניווט תחתון)

### Tab 1 — בית / סיכום שבועי (Home)
**כרטיסי סיכום (3 cards):**
- כרטיס ירוק: סה"כ שבועי (כל הילדים), מספר ימים, כיתוב "לב ב-X שע' יחד"
- כרטיס ורוד (לני): שעות שבוע, ימים, פגישות
- כרטיס כחול (אריאל): שעות שבוע, ימים, פגישות

**ניווט שבועי:**
- כפתורי ← הקודם / השבוע / הבא →
- תצוגת טווח תאריכים (DD.MM – DD.MM.YYYY)

**גרף השוואה (bar chart אופקי):**
- שורה כחולה = אריאל (X שע')
- שורה ורודה = לני (X שע')
- רוחב יחסי לפי כמות שעות

---

### Tab 2 — הוספת ביקור (Add)
**טופס:**
- ילד/ה: Dropdown עם תמונות/אמוג'י (ברירת מחדל: אריאל)
- תאריך: Date picker (ברירת מחדל: היום)
- שעת התחלה: Time picker
- שעת סיום: Time picker
- חישוב אוטומטי: "X שעות"
- הערות: שדה טקסט חופשי (אופציונלי)
- כפתור "הוסף +" ורוד

**ולידציה:**
- סיום > התחלה (חובה)
- תאריך חובה

---

### Tab 3 — רשימת ביקורים (History)
**שני tabs:**
- "השבוע הנוכחי" — מציג ביקורים של השבוע הנוכחי
- "כל הבייביסיטינגים" — כל הביקורים ממוינים לפי תאריך (חדש → ישן)

**כרטיס ביקור:**
- אייקון הילד (ורוד/כחול) + שם
- תאריך (יום בשבוע עברי + תאריך)
- שעת התחלה — שעת סיום
- מספר שעות (badge עגול)
- הערות (אם קיימות)
- כפתור מחיקה (אייקון אשפה, אישור לפני מחיקה)
- כפתור עריכה (עיפרון) — פותח את הטופס עם הנתונים הקיימים

---

### Tab 4 — ילדים (Children)
**כרטיסי הילדים:**
- כרטיס ורוד (לני): שם, אמוג'י, שם משפחה, סה"כ שעות היסטוריות
- כרטיס כחול (אריאל): שם, אמוג'י, שם משפחה, סה"כ שעות היסטוריות
- לחיצה → עריכת שם המשפחה

## דרישות טכניות

| דרישה | פרטים |
|--------|-------|
| קובץ | HTML יחיד (inline CSS + JS) |
| שפה | ממשק עברי מלא, dir="rtl" |
| שמירת נתונים | localStorage (אין שרת) |
| Mobile-first | מינימום 375px עד 430px viewport |
| ניווט | Bottom navigation bar (4 tabs) |
| גופן | Heebo מ-Google Fonts |
| עיצוב | רקע #F5F2EE (קרם), cards מעוגלים, צלליות עדינות |
| ביצועים | לא תלוי ב-CDN חוץ מ-Google Fonts (אפשר להטמיע) |
